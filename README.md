## ℹ️ Overview

**Time Off Request Generator** is a fun little web app built for anyone who has ever stared at a blank email trying to figure out how to say *"I just really need a day off"* in a way that sounds professional.

Pick your real reason (Dog's Birthday, Hangover Recovery, RIP to My Motivation), crank the corporate jargon dial up to extreme, and watch your excuse transform into something that belongs in a Fortune 500 memo. Built purely for fun and shared with coworkers who needed a good laugh.

Built with plain HTML, CSS, and JavaScript — no frameworks, no fuss.

## 🚀 Usage

Open the app in your browser, fill in three fields, and hit **Generate Request**:

```
Reason:              Mental Health Day (Netflix Marathon)
Corporate Jargon:    Extreme (Peak Synergy)
Number of Days:      2
```

**Output:**

```
Hi Team,

I'm leveraging 2 days to strategically realign my neurological assets 
and synergize my psychological KPIs to drive transformative mindshare 
in our value proposition ecosystem.

Thanks for understanding.
```

Hit **Copy to Clipboard** and paste it straight into your email. You're welcome. 🎉

## ⬇️ Installation

No installation needed! This is a plain HTML file — just open it in your browser.

### Option 1 — Download and open locally

1. **Clone the repository:**

```bash
git clone https://github.com/ninitwin4/time-off-request-generator.git
```

2. **Navigate into the project folder:**

```bash
cd time-off-request-generator
```

3. **Open the file in your browser:**

```bash
open index.html
```

Or simply double-click `index.html` in your file explorer.

> No installs, no dependencies, no synergy required. ✅
